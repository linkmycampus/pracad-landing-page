# PRACAD Technologies — Landing Site

Marketing site for **PRACAD Technologies Limited**, the technology arm of the PRACAD Group.

## Stack

- Next.js (App Router) + TypeScript
- CSS Modules + design tokens (Ink / Paper / Signal)
- Manrope via `next/font`
- Lucide icons

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Home |
| `/about` | Company, vision, mission, values |
| `/approach` | Discover → Build → Connect → Scale |
| `/products` | Product index |
| `/products/linkmycampus` | Flagship product |
| `/contact` | Enquiry form (UI only until backend is wired) |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Notes

- Colour and type are a **working system** until official brand assets arrive.
- Contact details and form delivery are intentionally placeholder.
- Do not invent products, metrics or testimonials beyond the brief.
